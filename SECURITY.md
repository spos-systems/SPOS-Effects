# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability in SPOS Effects, please report it to us privately — do not open a public GitHub issue for security reports:

- WhatsApp: https://wa.me/218935535606
- Website: https://spos.ly

Please include as much detail as possible: the affected file or effect, steps to reproduce the issue, and its potential impact. We will review the report and respond as soon as possible.

## ملاحظة بالعربية

إذا اكتشفت ثغرة أمنية في SPOS Effects، يرجى إبلاغنا بشكل خاص عبر واتساب (https://wa.me/218935535606) أو من خلال موقعنا (https://spos.ly)، ولا تفتح issue عاماً على GitHub للإبلاغ عن الثغرات الأمنية. النسخ المدعومة حالياً هي 1.0.x، وسنراجع البلاغ ونرد عليك في أقرب وقت ممكن.
